Malla Unidimensional y Discretización Nodal

El dominio continuo $[0, L]$ se divide en $n_e$ elementos lineales de igual longitud $l_e = L / n_e$. Los puntos de unión representan los $n_n = n_e + 1$ nodos donde se calcularán las temperaturas incógnita.

$$l_e = \frac{L}{n_e}, \quad x_i = i \cdot l_e \quad (i = 0, 1, \dots, n_e)$$

Tabla de Conectividad Elemento - Nodo

Mapea la numeración local $(1, 2)$ de cada elemento finito a los índices globales en toda la barra. Es la estructura de datos medular para el ensamblaje computacional en Python / C++.

Funciones de Forma de Lagrange e Interpolación

Dentro de cada elemento, la temperatura se interpola linealmente mediante dos funciones base: $N_1(x_{loc}) = 1 - \frac{x_{loc}}{l_e}$ y $N_2(x_{loc}) = \frac{x_{loc}}{l_e}$. Cumplen la propiedad delta de Kronecker y partición de la unidad ($N_1 + N_2 = 1$).

$$T^{(e)}(x_{loc}) = N_1(x_{loc}) \cdot T_1^{(e)} + N_2(x_{loc}) \cdot T_2^{(e)}$$

Formulación Débil (Galerkin) e Integración por Partes

Partiendo de la ecuación diferencial fuerte de calor $-k \frac{d^2T}{dx^2} = Q$, al sustituir una aproximación discreta se produce un residuo no nulo $R(x)$. El método de Galerkin exige que la proyección ponderada del residuo sea cero usando las funciones de forma como pesos ($w_i = N_i$).

$$\text{Formulación Fuerte: } -k \frac{d^2T}{dx^2} - Q = 0 \quad (\text{Requiere } C^2)$$ $$\text{Integración por partes: } \int_{0}^{l_e} k \frac{dT}{dx} \frac{dw}{dx} dx = \int_{0}^{l_e} Q w \, dx + \left[ k \frac{dT}{dx} w \right]_{0}^{l_e} \quad (\text{Requiere sólo } C^0)$$
💡 Clave Pedagógica para la Tesis: Al integrar por partes, rebajamos la derivada de orden 2 a orden 1. Esto permite usar funciones de interpolación lineales muy sencillas y garantiza que el sistema matricial resultante sea simétrico y definido positivo.

Matriz de Rigidez Global Ensamblada $[K]$

Cada elemento genera una submatriz local $K^{(e)} = \frac{k}{l_e}\begin{bmatrix}1 & -1 \\ -1 & 1\end{bmatrix}$. Estas submatrices se superponen en los nodos compartidos, generando la estructura tridiagonal global. Las filas 1 y $n$ se modifican para imponer las temperaturas Dirichlet.

Fila con Condición Dirichlet Diagonal Acoplada ($2k/l_e$) Acoplamiento Fuera de Diagonal

Solución del Sistema y Distribución Térmica $T(x)$

Tras resolver el sistema algebraico $[K]\{T\} = \{F\}$, obtenemos el vector de temperaturas nodales. Con $Q > 0$ se observa la concavidad parabólica exacta del perfil de calor.

Fundamento Matemático del Método de Elementos Finitos en 1D

1. Ecuación de Gobierno (Forma Fuerte)

La transferencia de calor unidimensional en estado estacionario con conductividad uniforme $k$ y generación interna distribuida $Q(x)$ está regida por la ecuación de Poisson:

$$-k \frac{d^2 T(x)}{dx^2} = Q(x), \quad x \in [0, L]$$ $$\text{Sujeta a: } T(0) = T_1, \quad T(L) = T_n$$

2. Deducción de la Forma Débil (Método de Galerkin)

Para relajar el requisito de doble derivabilidad continua, multiplicamos por una función de prueba $v(x) \in H_0^1$ e integramos sobre un elemento arbitrario $[x_1, x_2]$ de longitud $l_e$:

$$\int_{x_1}^{x_2} \left( -k \frac{d^2 T}{dx^2} - Q \right) v(x) \, dx = 0$$

Aplicando integración por partes al término de segundo orden:

$$\int_{x_1}^{x_2} k \frac{dT}{dx} \frac{dv}{dx} \, dx = \int_{x_1}^{x_2} Q v \, dx + \left[ k \frac{dT}{dx} v \right]_{x_1}^{x_2}$$

3. Discretización con Funciones de Forma Lineales

Aproximamos la temperatura y la función de prueba mediante la misma base (Formulación de Galerkin Estándar):

$$T^{(e)}(x) = \sum_{j=1}^{2} N_j(x) T_j^{(e)}, \quad v(x) = \sum_{i=1}^{2} N_i(x) v_i$$

Sustituyendo en la forma débil, se obtienen las matrices elementales:

$$K_{ij}^{(e)} = \int_{0}^{l_e} k \frac{dN_i}{dx} \frac{dN_j}{dx} dx \implies K^{(e)} = \frac{k}{l_e} \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}$$ $$F_i^{(e)} = \int_{0}^{l_e} Q N_i \, dx \implies F^{(e)} = \frac{Q l_e}{2} \begin{bmatrix} 1 \\ 1 \end{bmatrix}$$

4. Ensamblaje Global y Solución Exacta de Validación

Para $Q = \text{cte}$, la solución analítica exacta contra la cual validamos el simulador es:

$$T_{\text{exacta}}(x) = T_1 + \frac{x}{L}(T_n - T_1) + \frac{Q}{2k} x (L - x)$$

Un resultado clásico y notable del FEM 1D con elementos lineales es que en los nodos la solución numérica coincide exactamente con la analítica (propiedad de mejor aproximación en norma de energía).

Implementación Modular en Python (fem_1d.py)

"""
Módulo de Elemento Finito (FEM) en 1D para Transferencia de Calor (Poisson)
Código desarrollado en la Tesis de Grado.
Basado en la cátedra de Enmanuel Araujo ING.
"""

from typing import List, Tuple

class Mesh1D:
    def __init__(self, L: float, ne: int, one_based: bool = True):
        self.L = float(L)
        self.ne = ne
        self.nn = ne + 1
        self.le = self.L / self.ne
        self.one_based = one_based
        self.nodes = [i * self.le for i in range(self.nn)]
        offset = 1 if self.one_based else 0
        self.connectivity = [[e + offset, e + 1 + offset] for e in range(self.ne)]

    def get_element_coordinates(self, elem_idx: int) -> Tuple[float, float]:
        return self.nodes[elem_idx], self.nodes[elem_idx + 1]

def linear_shape_functions(x_local: float, le: float) -> Tuple[float, float]:
    n1 = 1.0 - (x_local / le)
    n2 = x_local / le
    return n1, n2

def interpolate_temperature(T1: float, T2: float, x_local: float, le: float) -> float:
    n1, n2 = linear_shape_functions(x_local, le)
    return n1 * T1 + n2 * T2

def element_stiffness_matrix(k: float, le: float):
    c = k / le
    return [[c, -c], [-c, c]]

def element_load_vector(Q: float, le: float):
    c = Q * le / 2.0
    return [c, c]
